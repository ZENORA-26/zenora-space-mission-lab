# ZENORA Space Mission Lab — Version 5.4

## What's new in 5.4
- ZENORA logo and full brand name are displayed at the top of the left navigation sidebar.
- First-time visitors are welcomed with an eight-step guided tutorial.
- A persistent “New here? Take the tour” button lets visitors replay the tutorial.
- Tutorial includes navigation, mission design, spacecraft systems, analysis, campaign, compare/simulation, Orbit Lab/NASA data, teamwork and reports.
- Tutorial can be skipped, closed, or navigated backward and forward. Completion is remembered in the current browser.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.

ZENORA is an educational simulator. Its engineering estimates are illustrative and are not flight software or certified mission-design outputs.
