08 / FLIGHT DYNAMICS

Orbital mechanics laboratory

Explore idealized two-body orbit and transfer estimates.

ORBIT MODEL

Schematic, not to scale. Animation is illustrative.

Select a scenario and calculate to view orbital parameters.
Model assumptions: Idealized Keplerian two-body / Hohmann estimates. The Moon model does not solve the three-body Earth–Moon–Sun problem; the Mars model assumes circular coplanar planetary orbits. Values exclude launch-site, atmosphere, plane-change, finite-burn, gravity-loss, navigation and detailed capture effects. This is an educational model, not a flight-dynamics tool.
08 / PROJECT INFORMATION

About ZENORA

PROJECT INFO

Purpose

An interactive educational web application for exploring mission planning trade-offs.

Technology

HTML, CSS, JavaScript, Canvas 2D and NASA NeoWs REST API.

Limitations

Idealized orbital calculations and resource estimates only. No certified trajectories, thermal design, radiation transport or flight-performance analysis.
